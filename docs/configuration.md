# Configuration

Generated by `meshtastic-mcp docs generate` from `env_vars.py`; do not edit. These are
every environment variable the package reads. Set them in the MCP client's server entry
(`env`), or in the environment of `meshtastic-mcp serve` on a shared bench. The server
reads them when it starts, so restart it after a change.

## Server

| Variable | Effect |
| --- | --- |
| `MESHTASTIC_MCP_TOOLSETS` | Comma-separated tool groups to expose. Unset exposes the default groups; `all` adds every group but `legacy`, which comes only when named; `-group` drops one. See [toolsets.md](toolsets.md). |
| `MESHTASTIC_MCP_READ_ONLY` | `1` hides every tool that can change state. |
| `MESHTASTIC_MCP_CONFIRM` | `human` makes irreversible tools ask the human even when the agent passes `confirm=True`. See [safety.md](safety.md). |
| `MESHTASTIC_MCP_BACKEND` | `sdk` runs device tools through the Kotlin SDK CLI instead of meshtastic-python. `ble:` targets use meshtastic-python unless this is set. |
| `MESHTASTIC_MCP_SDK_CLI` | Path to the SDK `cli` launcher the SDK backend runs. |
| `MESHTASTIC_MCP_DATA_DIR` | Where leases, device names, snapshots and job state live. Defaults to the platform's user data dir. |
| `MESHTASTIC_MCP_LOG_DIR` | Where the recorder writes its streams. Defaults to a directory under the data dir. |
| `MESHTASTIC_MCP_CAPTURE_DIR` | Base directory for files tools write (screenshots, captures). Defaults to the working directory. |
| `MESHTASTIC_MCP_FLASH_LOG` | A file each flash and tool subprocess tees its output to as it runs. |
| `MESHTASTIC_MCP_TCP_HOST` | A `meshtasticd` TCP endpoint (`host` or `host:port`) listed first in `devices`. |
| `MESHTASTIC_REPLAY_OBSERVER_NUM` | The node number the simulated radio reports as its own. |

## Shared bench

| Variable | Effect |
| --- | --- |
| `MESHTASTIC_MCP_STANDALONE` | `1` makes the stdio server run on its own instead of bridging to this host's running `serve`. See [bench.md](bench.md). |
| `MESHTASTIC_MCP_TOKEN` | The bearer token `serve` requires, at least 32 characters. |
| `MESHTASTIC_MCP_TOKEN_FILE` | A file holding the `serve` token, read when `MESHTASTIC_MCP_TOKEN` is unset. |
| `MESHTASTIC_WORKSPACE` | A workspace holding a `meshtastic-mcp` checkout; `doctor` compares the running install and `serve` against it. |

## Source trees

| Variable | Effect |
| --- | --- |
| `MESHTASTIC_FIRMWARE_ROOT` | A firmware checkout. Enables the `firmware` group and source builds in `install`. |
| `MESHTASTIC_ANDROID_ROOT` | A Meshtastic-Android checkout, for the Android app tools. |
| `MESHTASTIC_APPLE_ROOT` | A Meshtastic-Apple checkout, for the iOS app tools. |
| `MESHTASTIC_SDK_ROOT` | A meshtastic-sdk checkout; the SDK CLI is found under its build output. |
| `MESHTASTIC_MCP_SOURCE_ROOT` | This package's own checkout, for the nightly bake. Defaults to the installed source's repository. |

## Web control plane

| Variable | Effect |
| --- | --- |
| `MESHTASTIC_MCP_WEB_DB` | The FleetSuite registry database. |
| `MESHTASTIC_MCP_ARTIFACT_DIR` | Where FleetSuite keeps build artifacts. |
| `MESHTASTIC_MCP_AUTO_ENRICH` | `0` stops FleetSuite reading device details on discovery. |
